# /brand — SortMyCover brand system v1.0.0

The single source every surface imports. Spec: master prompt 4D.4a/4D.4b. Approved look extracted from `docs/design/sortmycover-ad-mockup.html` and `landing/reference/sortmycover-landing.html` (DM Sans 800, tick disc 0.95em with the "M5 13l4 4L19 7" tick, tick ink in accent-text brown).

## What is where
| Path | What |
|---|---|
| `tokens.json` | Source of truth: colours (hex/rgb/cmyk), roles, type scale 32/24/18/16/14, spacing, radii, safe zones, logo paths |
| `tokens.css` / `tokens.md` | Generated by `npm run tokens`. CSS variables `--sm-*` + self-hosted DM Sans; md has the WCAG contrast table |
| `fonts/` | DM Sans latin 500/800 (woff2 + woff), OFL licence |
| `logo/` | SVG masters generated by `scripts/build-logos.mjs`: wordmark x4 colourways, stacked x4, tick mark, tick reversed, horizontal lock-up + line, endorsement lock-up, co-brand template + fictional sample, favicon glyph. Lettering is outlined paths (no `<text>`), except the co-brand template where the practice name is data |
| `favicon/` | favicon.svg (theme-aware), .ico 16/32/48, 32 px PNG, apple-touch 180, icon 192/512 (+ maskable), mask-icon, manifest, browserconfig, `favicon-check.html` |
| `templates/` | HTML templates (import `tokens.css` and `../logo/*.svg`): intro card, what-to-expect, reminder, feed (1:1, 4:5), Reels end-card, lower-third, 16:9 end-card, A4 document, email header, profile, cover, OG, intro video. Data arrives as `?d=<json>`; each file carries fictional defaults |
| `exports/render.mjs` | Renders every placement at exact size; writes `exports/manifest.json` |
| `exports/<surface>/` | The rendered PNGs (profile, cover, og, email, feed, reels, whatsapp, video-frames, gbp, documents, logo @1x/2x/3x) |
| `scripts/` | build-tokens, build-logos, build-favicon, render-intro-video, sync-landing-holding, check-no-hex |
| `../automation/templates/samples/` | `intro_card_sample.png`, `intro_video_sample.mp4` (Meta review samples, fictional adviser) |

## Re-render
```
cd brand && npm install        # opentype.js + DM Sans (only needed to rebuild logos)
npm run all                    # tokens -> logos -> favicon -> exports -> video -> sync to landing/holding
node scripts/check-no-hex.mjs  # acceptance: no hex outside tokens
```
Needs Playwright with Chromium (found automatically under `/opt/pw-browsers`, or set `CHROMIUM_PATH`), `ffmpeg` for the video, ImageMagick `convert` (optional, shrinks feed stills to <= 120 KB).
Pipeline use (intro cards): call `shot()` from `scripts/lib.mjs` with `templates/intro-card.html` and the broker's data (`adviser, practice, fsp, bio, languages_line, method_line, photo`).

## Do
- One amber, one tick, one type family, the line stated once per asset: "Sort your cover. 30 minutes. A real adviser."
- Clear space = tick circle height; wordmark min width 96 px; tick min 16 px.
- Body text off-white on charcoal or charcoal on off-white; text on amber is accent-text.
- Charcoal scrim behind any text on imagery; Reels top 250 / bottom 340 px free of text; FB cover content inside the 640 px centre.
- Label AI imagery with people ("AI-generated imagery", `ai_label` in the feed template). The real adviser appears only in WhatsApp intro media.
- Tick animates only as the single 400 ms draw (site load, video end-card).

## Don't
- No shields, umbrellas, family silhouettes, navy, stock families on white, text-heavy slides.
- Never stretch, recolour outside the palette, add gradients, shadows or outlines to the logo; never place it on busy photography without the scrim.
- Never ask Google Flow for the logo, icons or any text-bearing element.
- No "best", "cheapest", "#1", "guaranteed"; CTA says "check", never "get a quote".
- No hex values outside `tokens.json`/`tokens.css` (generated SVGs carry `rgb()` derived from tokens; `manifest.webmanifest` and `browserconfig.xml` need hex by platform format).
