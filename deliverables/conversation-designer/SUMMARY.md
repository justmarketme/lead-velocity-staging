# conversation-designer — summary (written by the orchestrator; the harness does not let sub-agents write report files)

Thandi is built in the two layers 4.11 asks for: buttons, lists, the booking Flow and templates carry every structured step with no generated text; the LLM handles typed messages only, through regex pre-filter → health/ID masking → Haiku intent/slot JSON → `decide()` in code → Haiku phrasing → regex output gate → Haiku guardrail classifier → tone check → fixed lines added by code (deferral, AI disclosure, handoff, STOP; EN + AF; never model-written). `conversation/` holds persona, state machine, deferral lines, handoff rules, six prompt files and the runtime modules (`guardrail.mjs`, `logic.mjs`, `lines.mjs`) automation-engineer pastes into W07. `knowledge/faq.md` is the single corpus (25 answers + 8 always-defer topics, compliance sign-off slot) for Thandi, comments, DMs and the page. `evals/` holds the 238-turn golden set (38 Afrikaans), 50 red-team prompts, 20 scripts, 5 briefs, the rubric and `run.mjs`: the dry run (code layer only) scores FAIS 100%, tone 100%, STOP 100%, pre-filter 56/56 with 0/176 false positives, output gate 50/50, redaction 14/14; the live Haiku run starts when ANTHROPIC_API_KEY exists and writes to `evals/results/`. Writing the golden cases exposed and fixed six regex gaps. Wording follows the approved chat replay wherever it does not break a 4.11 rule; deviations and the open questions (proactive first message on web leads, qualifying order, STOP-while-booked, handoff hours, extra languages) are logged in `build/needs-human-log.md`; compliance-qa sign-off of the FAQ, red-team set and Afrikaans lines is pending (Phase 4).
