7 · Hand-off

Two values to Claude. Never through chat.

The Application (client) ID and the secret Value. Pick one way.

✕ Never paste the secret into a chat, an email or WhatsApp.
Option 1 · a local file
lv-release\supabase\.env.ms-oauth
# paste, save, close. Never committed (.gitignore: .env.*)MS_CLIENT_ID=your-Application-client-IDMS_CLIENT_SECRET=your-secret-Value
never goes into git
Option 2 · set them yourself
Terminal · lv-release
$ supabase secrets set --project-ref cmsylaupctrbsvzrgzwy MS_CLIENT_ID=… MS_CLIENT_SECRET=…

Claude does the rest

  • MS_REDIRECT_URI (the callback address)
  • MS_OAUTH_STATE_SECRET (random, 32+ characters)
  • PORTAL_URL = https://leadvelocity.co.za
  • Deploy the ms-oauth sign-in function
  • Record the secret's expiry date
  • Same ID and secret in n8n, for token refresh
