# Accessibility checklist (WCAG 2.2 AA) for the landing template

Owner: landing-page-builder. Spec: 6B.4 (contrast >= 4.5:1 text, 44 px targets, labels, focus order). Automated half: `a11y.mjs` (axe-core, WCAG 2.1 A + AA,
runs in `make test`) plus `quiz.spec.ts` (target sizes, labels via role queries, keyboard path); the rest is the manual list below. `lighthouse.sh` also reports
the accessibility category (needs network once).

## Manual checks (tick per release)
- [ ] Tab order = visual order: skip link, hero CTA, quiz options, Back/Next, details, consent, send, FAQ, footer links, sticky CTA. No tab traps.
- [ ] Every focusable element shows a 3 px visible focus ring (radio cards show it on the card via `:has(input:focus-visible)`).
- [ ] Screen reader (VoiceOver iOS / TalkBack): each question is announced as a group with its question as legend; selected option is announced as checked; progress bar announces "Progress, n of 7".
- [ ] On each step change the new heading receives focus (so the question is read out) and the page scrolls to the card. `#live` is polite status only.
- [ ] Errors: field gets `aria-invalid="true"` and `aria-describedby` points at the message; focus moves to the first invalid field on submit; `#formErr` and `#bookErr` are `role="alert"`.
- [ ] Keyboard-only: arrow keys / space select a radio card without advancing; a visible "Next" button appears; Back works; Enter in the form does not submit before step 6.
- [ ] Mouse/touch: single tap on a card advances after 220 ms (the hint says "Tap one"). Reduced-motion: no animation, instant scroll.
- [ ] Targets: every `.opt`, `.btn`, `.slot`, `.method`, `.link`, input, summary and footer link >= 44 x 44 CSS px (asserted in `quiz.spec.ts`).
- [ ] Reflow: 320 px wide and 400% zoom, no horizontal scroll, no clipped text (asserted at 390 px).
- [ ] Text spacing override (line-height 1.5, letter 0.12em, word 0.16em, paragraph 2em) does not clip text.
- [ ] `lang` attribute set per page (`en-ZA`; `af` for the Afrikaans variant).
- [ ] The privacy link in the consent line opens in a new tab and says so (visually-hidden text).
- [ ] Page is usable with CSS dark mode (prefers-color-scheme: dark) and with forced colours (cards keep a visible border).
- [ ] No time limit, no auto-playing media, no content that flashes. Auto-advance after a tap is announced by the hint "Tap one" (WCAG 3.2.2).
- [ ] Form: labels are visible and programmatically tied (`for`/`id`); autocomplete tokens `given-name`, `tel`, `email`; mobile keyboards `tel` / `email`.
- [ ] Honeypot field is off-screen, `aria-hidden`, `tabindex=-1` (not reachable by AT or keyboard).
